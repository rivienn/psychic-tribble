# 🧠 EPIO-ML: Голосовой AI-агент по недвижимости

**EPIO-ML** — это локальный агент на основе LLaMA, способный вести голосовой диалог с пользователем, анализировать данные, подключаться к БД, парсить сайты и сохранять результаты. Использует локальные ML-модели и TTS/STT-движки для полной автономии.

## 🔧 Стек технологий

- 🧠 **LLaMA (GGUF) через GPT4All** — локальный LLM
- 🗣️ **whisper + Coqui TTS** — преобразование речи в текст и обратно
- 🏡 **langchain** — обёртка вокруг agenta
- 📦 **SQLAlchemy / pandas** — работа с БД и данными
- 🕸 **selenium** — парсинг сайтов с недвижимостью
- 🧪 **torch / TTS / librosa** — аудио-пайплайн
- 🧹 **onnxruntime** — выделение голоса из аудио

## 📁 Структура проекта

```
Abracadabra-ml/
├── agent_core/          # Ядро агента на LangChain
├── audio_processing/    # Преобразование аудио <-> текст
├── db_connector/        # Работа с БД: чтение/запись
├── llama_agent/         # Управление промтами, контекстом и моделью
├── scraping/            # Парсинг недвижимости
├── config.py            # Все пути и параметры
└── run.py               # Запуск
```

## 🚀 Быстрый старт

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Подготовьте директории `./data/text`, `./data/speech`, `./data/real_estate` и скачайте модель GGUF.

3. Запустите агента:

```bash
python run.py input.txt output.txt
```

4. Используйте голосовой ввод — агент обработает, прогонит через LLM и ответит голосом или текстом.

## 🤖 Модули

- **agent_core** — фабрика и интерфейс LangChain агента.
- **llama_agent** — логика LLM + роутинг промтов.
- **audio_processing** — запись, транскрибация, синтез речи.
- **db_connector** — экспорт результатов, чтение из SQL.
- **scraping** — сбор данных с Avito и других сайтов.
- **tools.py** — кастомные утилиты и langchain-инструменты.

## 🧪 Примеры использования

- 📞 Голосом: *"Подбери мне 2-комнатную квартиру в центре до 10 млн"*
- 🔍 Через БД: извлечение записей и построение выводов
- 🕷 Автоматический парсинг сайтов с недвижимостью
